import requests

response = requests.post(
    "https://api.sentryai.ai/v1/chat/completions",
    headers={
        "Authorization": f"Bearer {SENTRY_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "model": "sentry-1",
        "messages": [
            {"role": "system", "content": "You are a concise, accurate assistant."},
            {
                "role": "user",
                "content": [
                    {"type": "text", "text": "Summarize this image and the linked report."},
                    {"type": "image_url", "image_url": {"url": "https://example.com/diagram.png"}},
                    {"type": "file_url", "file_url": {"url": "https://example.com/report.pdf"}},
                ],
            },
        ],

        # --- sampling control ---
        "temperature": 0.7,
        "top_p": 1.0,
        "top_k": 40,
        "max_tokens": 2048,
        "stop": ["\n\nEND"],
        "seed": 42,
        "presence_penalty": 0.0,
        "frequency_penalty": 0.0,
        "n": 1,

        # --- streaming ---
        "stream": True,

        # --- structured output ---
        "response_format": {
            "type": "json_schema",
            "json_schema": {
                "name": "summary",
                "schema": {
                    "type": "object",
                    "properties": {
                        "summary": {"type": "string"},
                        "key_points": {"type": "array", "items": {"type": "string"}},
                    },
                    "required": ["summary", "key_points"],
                },
            },
        },

        # --- function calling ---
        "tools": [
            {
                "type": "function",
                "function": {
                    "name": "get_weather",
                    "description": "Get current weather for a location",
                    "parameters": {
                        "type": "object",
                        "properties": {"location": {"type": "string"}},
                        "required": ["location"],
                    },
                },
            }
        ],
        "tool_choice": "auto",

        # --- extended reasoning ---
        "reasoning": {"enabled": True, "effort": "high"},

        # --- live web search & crawling ---
        "web_search": {"enabled": True, "max_results": 5},

        # --- context window ---
        "context_window": 1000000,
    },
    stream=True,
)

for line in response.iter_lines():
    if line:
        print(line.decode())

Docs

      
Everything you need to send your first request.

    

    

      
Quickstart

      
Create a key from your console, then send a request to /v1/chat/completions with an Authorization: Bearer header. The endpoint is OpenAI-compatible, so existing SDKs and client libraries work without modification — just change the base URL and key.

      
Authentication

      
Every request must include your API key as a bearer token: Authorization: Bearer sk-sentry-.... Keys can be named, listed, and revoked independently from your console. Revoking a key takes effect immediately.

      
Endpoints

      
POST /v1/chat/completions — send messages, get a completion or a stream.

      GET /v1/models — list available model identifiers.

      
Rate limits

      
Every response includes X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset headers so you can track usage against your daily cap in real time. Exceeding the cap returns a 429 with a Retry-After header.

      
Streaming

      
Set "stream": true to receive the response as server-sent events. Each event contains a partial delta; the stream ends with a data: [DONE] line.

      
Structured output

      
Pass a response_format of type json_schema to constrain output to a schema. Responses that don't validate are automatically retried once server-side before being returned.

      
Function calling

      
Define functions under tools and set tool_choice to auto, required, or a specific function name. The model returns a tool_calls array instead of plain text when it decides to call one.

      
Multimodal input

      
Attach image, audio, video, or file content directly in the messages array alongside your text, using image_url or file_url content blocks.

      
Extended reasoning

      
Set reasoning.enabled to true and choose an effort of low, medium, or high for problems that benefit from longer deliberation before answering.

      
Live web search

      
Set web_search.enabled to true to let a request ground its answer in live pages, with max_results controlling how many sources are consulted.

      
Errors

      
Errors follow {"error": {"type": "...", "message": "..."}}. Common types: invalid_request, authentication_error, rate_limit_exceeded, server_error.

      
SDKs

      
No dedicated SDK needed — point any OpenAI-compatible client at https://api.sentryai.ai/v1 and swap in your Sentry key.

Privacy policy

      
What we collect and how it's used.

    

    

      
What we collect

      
Account email and password (stored hashed, never in plain text), request metadata (timestamps, token counts, endpoint called), and anything you submit in a request body needed to serve that request.

      
What we don't do

      
We don't sell request content to third parties, and we don't use free-tier request content to train models without separate, explicit opt-in.

      
How we use it

      
To authenticate requests, enforce rate limits, serve your console usage stats, and diagnose errors. Nothing is used for advertising.

      
Retention

      
Request metadata used for rate-limit accounting is retained for 30 days.

      
Third parties

      
We share the minimum data needed with infrastructure providers that keep the API running (hosting, logging). None of them are permitted to use your data for their own purposes.

      
Your choices

      
You can export your account's usage data, sign out from the console, or contact us to correct inaccurate information, all from the console.
